# 产品需求与验收标准

版本：0.9.3（源码，尚未打包）；更新：2026-09-23。

## 1. 产品目标

把闲置手机、平板或桌面支架上的 Android 设备变成易读的全屏时钟。用户可以按空间布置选择横屏或竖屏、时区、日期信息、背景和字体。首版优先保证离线可用、时间正确、设置可恢复。

## 2. 术语与约定

| 术语 | 首版定义 |
| --- | --- |
| 日历开关 | 在时钟下方显示或隐藏**公历日期与星期**；不弹出月视图。月视图列入后续版本。 |
| 中国农历开关 | 显示或隐藏农历月、日，闰月前显示“闰”。日期随所选时区对应的当地日期变化。 |
| 填充 | 保持原始宽高比，裁切超出屏幕的部分，画面无空白。 |
| 适应 | 保持原始宽高比，完整显示背景内容；宽高比不同时留出背景色空白。 |
| 拉伸 | 图片或视频铺满整个屏幕，允许比例变化。 |
| 平铺 | 图片和动图按原尺寸重复排列，可在预览中缩放、平移；视频选平铺时按适应显示。 |
| 动态背景 | 首版包括 GIF、动态 WebP、设备可播放的本地视频；视频静音循环。 |
| 多时区切换 | 一个时刻显示一个时区，可随时切换；不在同屏并列多个时区。 |

## 3. 使用场景

1. 桌面常亮：手机横放，隐藏日期与秒数，选一张静态图。
2. 跨国协作：竖屏显示伦敦或纽约时间，保留公历与星期。
3. 节日与家庭场景：显示北京时间、公历与农历，使用自选字体和动图。

## 5. 页面与交互

### 时钟页

- 全屏背景 → 可调暗度层（默认透明）→ 居中时间 → 可选的时区、公历、农历文本。
- 向右滑打开左侧设置面板；向左滑打开右侧自定义面板。没有设置按钮。
- 时钟页底部不显示手势提示文字。
- 面板不占满屏幕；反向滑动、点击面板外侧或按返回键可关闭。面板关闭时返回键可以离开应用。
- 时间大小随可用空间缩放，横竖屏均保留边距。

### 左侧设置面板

- 应用语言（默认跟随系统）、时区选择（当前 UTC 偏移前缀）、时区文字开关、公历、农历、秒数、屏幕方向、左右侧栏背景透明度。

### 右侧自定义面板

- 默认背景颜色四条折叠滑条、背景布局（填充、适应、拉伸、平铺）、背景亮度、并排的图片和视频导入按钮、背景位置预览、恢复默认背景。
- 背景来源可选单个背景或播放列表；“管理播放列表”在右侧栏内打开独立管理页，保留时钟画面可见区域。
- 列表管理页可选择已保存列表、新建、另存为、重命名、删除、一键清空；顶部提供暂停与继续。项目按每页 50 项展示，提供缩略图、名称、点选播放、排序和删除。图片与视频各自的显示模式、列表亮度、淡出淡入、随机、循环和图片停留时间集中在该页；修改这些播放设置不重播当前媒体。
- 列表管理页提供“添加文件夹”；扫描和导入在后台进行，完成后显示添加数量与失败数量。
- 字体预设和导入字体列表（导入项可删除）、加粗、阴影、默认折叠的颜色控制、导入字体、恢复默认字体。
- 字体颜色的“颜色强度”控制 HSV 明度，“颜色”控制色相，“饱和”控制饱和度；透明度同时作用于文字与文字阴影。
- 所有选择即刻写入本地设置并呈现在时钟页。

### 背景预览模式

- 支持静态图片、GIF、动态 WebP；视频支持填充、适应、拉伸，选择平铺时按适应显示。
- 预览时隐藏时钟和侧栏，显示完整背景；单指移动，双指以手势中心缩放，缩放范围为原始适配比例的 1–4 倍。
- 底部中间显示半透明的“重置”“保存”“取消”小按钮。重置仅改变当前预览；保存持久化；取消恢复上次保存的位置。
- 为避免出现空白边缘，移动范围限制在图片覆盖屏幕的区域内。选择新背景时位置恢复居中。

## 6. 边界条件

- 系统时钟错误时应用无法自行校时；没有联网校时功能。
- 系统时区选项始终跟随设备，固定时区选项使用 IANA 标识。
- 背景文件被删除、移动或云盘授权失效时回退到深色背景，并提示重新选择。
- 视频解码取决于设备支持的格式；不提供媒体转码。
- 字体文件限定 TTF / OTF 和 20 MB；格式无效时保持原字体。
- 第三方文件选择器可能不提供长期 URI 授权，此时提示并要求重新选择。
- 提供主要地区的固定时区和系统时区；完整时区搜索是后续需求。
- 播放列表中新导入的图片和视频保留原址及读取授权，图片仅缓存缩略图；旧版已复制图片继续使用。原文件被移动、删除或云端不可用时，失效媒体播放时跳过，全部失效时回退纯色背景并提示。

## 7. 暂不纳入首版

- 同屏世界时钟、闹钟、倒计时、天气、网络校时。
- 月历网格、法定节假日、农历节气和宜忌。
- 在线背景库、云同步、音乐或视频声音。
- 桌面小组件、锁屏显示和壁纸服务。

## 8. 后续迭代建议

1. 时区搜索、收藏及同屏多时区卡片。
2. 可调文字位置、字号和 12 小时制。
3. 月历面板、节假日与无障碍语义优化。
4. 视频背景的硬件兼容性与功耗配置。
