# 测试计划与发布检查

## 1. 环境

- Android Studio，JDK 17，Android SDK Platform 36。
- 至少一台 Android 9 / API 28 设备或模拟器，以及一台较新版本设备。
- 准备宽图、竖图、透明 PNG、GIF、动态 WebP、短视频、合法 TTF / OTF、损坏字体文件。

## 2. 手工验收用例

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| T01 | 启动、等待 70 秒 | 时间每秒变化，分钟进位正确；无明显重复或跳帧。 |
| T02 | 关闭再开启秒数 | `HH:mm` 与 `HH:mm:ss` 切换，时间布局仍居中。 |
| T03 | 切换北京、东京、纽约、系统时区 | 时间、公历日期与星期随时区变化；重启后保留。 |
| T04 | 测试一个夏令时切换前后的时刻 | 所选时区遵守系统时区数据库；无硬编码 UTC 偏移。 |
| T05 | 分别关闭公历、农历，再开启 | 对应信息隐藏和恢复，无空白行。 |
| T06 | 使用已知农历新年、闰月日期 | 农历月日和“闰”标识与可信日历交叉核对。 |
| T07 | 选择横屏、竖屏、跟随设备并旋转 | 页面重排，主时间不裁切，设置按钮可触达。 |
| T08 | 选横图和竖图，切换填充与拉伸 | 填充不留空白；拉伸铺满屏幕。 |
| T09 | 选择 GIF / 动态 WebP、切出再返回 | 动画播放；后台停止；返回后恢复。 |
| T10 | 选择短视频，切出再返回 | 静音循环，画面在时间文字后；后台停止。 |
| T11 | 导入合法字体，重启应用 | 字体仍生效；恢复默认字体有效。 |
| T12 | 导入损坏或超大字体 | 显示失败提示，原字体不丢失。 |
| T13 | 删除或撤销背景文件，再启动 | 页面继续显示时间，背景回退且有提示。 |
| T14 | 重启设备、重启应用 | 设置和已授权的背景文件保持可用。 |
| T15 | 设置系统时间跨日或更改系统时区 | 当前页在下一次刷新时更新显示。 |
| T16 | 关闭时区文字后切换时区 | 时区说明隐藏，主时间仍按新时区变化。 |
| T17 | 从时钟页分别向右、向左滑动 | 左侧打开时间设置，右侧打开自定义；两面板均不占满屏幕。 |
| T18 | 在面板中反向滑动、点击外侧、按返回键 | 面板关闭；再次滑出时设置仍保留。 |
| T19 | 启动默认配置并选择明亮图片 | 背景保持原始亮度；时钟页底部没有提示文字。 |
| T20 | 在右侧面板拖动背景亮度滑杆 | 图片亮度从 100% 降至 30%，文字亮度不随之变化；重启后设置保留。 |
| T21 | 分别开关文字阴影与加粗 | 两项独立控制，立即生效，重启后保留。 |
| T22 | 对比本版与 0.2.0 APK 的签名证书 | 证书 SHA-256 完全一致；相同签名的已安装版本可覆盖升级。 |
| T23 | 将背景亮度设为任意值，打开或关闭左右面板 | 面板外可见背景的亮度保持不变。 |
| T24 | 在右侧面板反复横向拖动亮度滑杆 | 亮度连续变化，面板始终保持打开；松手后可用反向滑动关闭。 |
| T25 | Android 12 及以上更换系统壁纸配色并重开应用 | 按钮颜色跟随系统动态色；Android 9–11 显示回退色。 |
| T26 | 调节左侧透明度并打开右侧面板 | 两侧面板背景透明度一致；时钟与背景图亮度不变。 |
| T27 | 查看北京、纽约、伦敦、加德满都等时区 | 列表最前的正负号及半小时/45 分钟偏移正确；夏令时地区显示当前偏移。 |
| T28 | 选图片进入预览，单指移动、双指缩放后保存并重启 | 预览期间无抽屉误触；保存后位置保留且无空白边缘。 |
| T29 | 预览中重置、取消、保存分别操作 | 重置只影响临时预览；取消恢复上次保存位置；保存持久化当前状态。 |
| T30 | 选视频背景点击预览 | 出现暂不支持提示；原有视频播放与亮度设置正常。 |
| T31 | 点击并排的“选择图片”和“选择视频” | 图片进入系统相册选图界面（不支持时进入图库或图片选择界面）；视频进入文件选择器。 |
| T32 | 导入图片或动图后重启应用，再换用视频 | 图片在重启后仍可显示或播放；视频能静音播放；切换后背景类型正确。 |

T04 和 T06 可使用可注入的时钟做自动化测试；当前首版以手工测试为准。为了降低设备误差，验收时需记录系统时区数据库版本和设备时间。

## 3. 构建与检查

```powershell
cd time-display-android
.\gradlew.bat :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`，版本化副本位于 `releases/`。2026-09-23 已用临时安装在 `.tooling/` 的 SDK 与 Gradle 完成 0.4.1 的 `assembleDebug`。设备验收尚未执行，尤其需要检查相册选择器回退、图片预览手势、动态色与不同时区偏移。

## 4. 发布前剩余工作

1. 真机和模拟器上完成上表验收，修复兼容性问题。
2. 为大图增加按屏幕尺寸解码，做持续播放内存与功耗测试。
3. 添加应用图标、版本信息、错误反馈入口与必要的无障碍检查。
4. 依据目标分发渠道确定 `targetSdk`、签名和隐私说明。
