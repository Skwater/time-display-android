# 测试计划与发布检查

## 1. 环境

- Android Studio，JDK 17，Android SDK Platform 36。
- 至少一台 Android 9 / API 28 设备或模拟器，以及一台较新版本设备。
- 准备宽图、竖图、透明 PNG、GIF、动态 WebP、短视频、合法 TTF / OTF、损坏字体文件。

| T27 | 查看北京、纽约、伦敦、加德满都等时区 | 列表最前的正负号及半小时/45 分钟偏移正确；夏令时地区显示当前偏移。 |

| T31 | 点击并排的“选择图片”和“选择视频” | 图片进入系统相册选图界面（不支持时进入图库或图片选择界面）；视频进入文件选择器。 |
| T32 | 导入图片或动图后重启应用，再换用视频 | 图片在重启后仍可显示或播放；视频能静音播放；切换后背景类型正确。 |
| T33 | 查看字体菜单、切换各预设并恢复默认字体 | 首项文案为“默认字体”，第二项为轻体无衬线；衬线、等宽及导入字体依次排列；恢复默认后首项被选中。 |

| T35 | 查看字体菜单并让导入字体文件不可读后重启 | 菜单显示“衬线”“等宽”；字体加载失败时钟仍可显示，回退到默认字体。 |
| T36 | 依次导入两种不同名称的 TTF / OTF，重启应用 | 两个名称均出现在字体菜单中，每项能独立选择；重启后保留。 |
| T37 | 删除未选中的导入字体，再删除当前字体 | 每个导入项右侧的“×”只删除对应副本；删除当前字体后自动选中默认字体，不影响其他字体。 |
| T38 | 从安装过 0.4.2 的设备升级并打开字体菜单 | 旧版已导入字体迁移到列表，仍可选择和删除；旧版预设字体选择保持。 |
| T39 | 展开字体颜色，依次拖动四条滑条，关闭再重开应用 | 默认折叠；四条轨道左端和右端对齐、渐变可见；文字和阴影立即更新，数值重启后保留。 |
| T40 | 把透明度调至 0，再恢复 100%；测试低亮度与饱和色 | 0 时文字及阴影都不可见；恢复后可见，明度、色相、饱和度各自生效。 |
| T41 | 对静态图和 GIF / 动态 WebP 切换平铺，进入位置预览后缩放、平移 | 画面按单元重复排列，缩放和平移实时生效；保存后重启仍保留；动图继续播放。 |
| T42 | 对视频选择四种背景布局 | 填充裁切、适应完整显示、拉伸铺满；平铺选项按适应显示，播放仍静音循环。 |
| T43 | 系统设中文与英文，应用语言选跟随系统、中文、英文 | 默认跟随系统；手选语言覆盖系统语言；左、右侧栏及日期、农历说明同步切换，重启后保留；系统选择器保持系统自身语言。 |
| T44 | 安装后查看桌面名称与图标 | 名称为“屏幕时钟”；图标是小圆角黑底、白色“T:me”，在不同启动器中保持清晰。 |
| T45 | 在左侧面板反复切换跟随系统、中文、英文 | 页面切换后顶部没有白条，通知栏和导航栏保持隐藏；无需重启即可正常显示。 |

| T47 | 从 0.6.1 覆盖安装，切换单个背景和空播放列表 | 旧背景与设置保留；空列表显示深色背景，时钟和面板仍正常。 |
| T48 | 批量导入静态图片、GIF / 动态 WebP 和视频，重启应用 | 列表显示名称与缩略图或视频标识，顺序和媒体授权保留；图片、动图按停留时间切换，视频播完切换。 |
| T49 | 长按拖动列表项、用上下箭头排序、删除条目 | 顺序即时更新，删除仅影响目标条目；重启后仍保留新顺序。 |
| T50 | 分别设置列表图片和视频的显示模式，再切回单个背景 | 两类媒体各使用自己的模式，默认填充且居中裁切；单个背景的模式和预览位置设置保持独立。 |
| T51 | 调整列表亮度、停留时间、随机、循环和淡出淡入开关 | 列表设置立即生效并持久化；关闭淡出淡入后直接切换，视频结束后进入下一项。 |
| T52 | 删除或撤销列表媒体文件访问权，再播放 | 可用条目继续播放；全部失效时纯色背景仍可显示时钟，并出现提示。 |
| T53 | 选择含图片、动图、视频和其他文件的文件夹，含一层子文件夹 | 可识别媒体按路径加入列表；非媒体文件跳过；视频在重启应用后仍能播放。 |
| T54 | 向 99 项列表导入两个以上文件，确认后继续；再次导入；选择读取失败的云端文件夹 | 首次达到 100 项时询问确认，确认后可超过 100 项；已达到 100 项的列表再次导入不重复询问；失败有提示，已有列表不丢失。 |
| T55 | 从文件夹导入图片和视频后重启，再移动或删除原文件 | 原文件仍在时凭保存的文件夹授权播放；移动或删除后对应条目无法播放并跳过，不影响其他项目。 |
| T56 | 从 0.7.1 覆盖安装，打开播放列表，重启应用 | 旧列表及顺序迁入默认列表；媒体仍可播放。 |
| T57 | 新建空列表、另存为、切换、重命名、继续添加与排序，然后重启 | 多列表、名称、项目和所选列表保留；另存为后的编辑不影响原列表。 |
| T58 | 清空或删除列表，并测试仅剩最后一个列表、共享图片和视频 | 清空仅影响当前列表；删除最后一个列表后出现新的空默认列表；其他列表引用的媒体保持可用。 |
| T59 | 导入超过 50 项并翻页，跨页用箭头排序或删除项目 | 每页最多 50 行，总数及页码正确；跨页操作后顺序仍正确。 |
| T60 | 从文件夹及相册导入图片，查看缩略图，重启后播放；从旧版覆盖安装 | 新图片只保留原 URI 和小尺寸缩略图，重启后能打开原文件；旧版已复制的图片仍可播放。 |

T04 和 T06 可使用可注入的时钟做自动化测试；当前首版以手工测试为准。为了降低设备误差，验收时需记录系统时区数据库版本和设备时间。

## 3. 构建与检查

```powershell
cd time-display-android
.\gradlew.bat :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`，版本化副本位于 `releases/`。0.9.0 已完成 `assembleDebug`，APK 版本号为 16 / 0.9.0，应用名为“屏幕时钟”。`apksigner verify` 通过，签名证书 SHA-256 为 `9E:2A:7F:51:06:CA:4D:71:91:3F:FF:F1:EC:C2:4A:21:20:88:9E:B0:6A:3E:BA:D2:15:5E:87:E6:0B:AD:07:03`，与此前版本一致。APK 文件 SHA-256 为 `7934A72ED339AF4D409A74030AEEF8F1120985E77966F5DD2055A971DC0F5D5F`。用户说明此前打包版本均已在设备上完成验收，并在本轮反馈了 0.8.0 的列表显示与播放问题；0.9.0 尚待设备验收，重点覆盖 T60–T63。
